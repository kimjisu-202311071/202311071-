# 산업연관표(2023) 분석 대시보드

한국은행 2023년 산업연관표 자료를 활용하는 정적 웹 대시보드입니다.

## 실행
정적 파일을 웹 서버 또는 GitHub Pages에 배포하면 됩니다. `index.html`을 브라우저에서 직접 열 경우 브라우저 정책에 따라 Worker/데이터 로딩이 제한될 수 있으므로 로컬 웹 서버 사용을 권장합니다.

## 자료
`data/` 폴더의 2023년 산업연관표 Excel 파일을 사용합니다. 원자료 출처와 기준 연도는 각 화면에 표시됩니다.

## 분석 목차
1. 요약
1) 산업요약
2) 총산출액, 부가가치액, 영향력계수, 중간투입율, 국산화율, 수입의존도 등 주요 경제지표를 확인하고 산업별 순위와 평균을 비교한다. 상위 1개, 10개, 20개로 각각 지표를 가로 막대그래프로 가시성 있게 나타냈다. 빨간 체크표시로 평균을 나타내 이 산업지표가 평균보다 상대적으로 어디에 위치해 있는지 한 눈에 볼 수 있다.
3) 원자료 탐색
산업연관표의 시트와 산업을 선택하여 원자료를 검색하고 산업 간 거래 내역을 확인한다.
2. 유발효과(원자료 탐색과 연결되어있다.)
1) 영향력 감응도 계수
산업별 전방 및 후방 연쇄효과를 확인하고 전체 산업 평균과 비교한다. 파이프라인으로 전방연쇄효과와 후방연쇄효과의 크기를 한 눈에 비교 가능하게 두 선의 굵기를 계수에 따라 가늘고 굵게 보이도록 설정했다. 오른쪽 방향으로 화살표를 집어넣어 각 계수의 영향력을 시각적으로 이해가 쉽게 나타냈다. 밑에 가로 막대 그래프인 영향력 계수와 감응도계수 또한 평균을 빨간색 체크표시로 나타내어 상대적으로 각 산업의 영향력이 어느 위치에 있는지 알 수 있게 하였다.
2) 산업 간 연결관계도
특정 산업을 중심으로 다른 산업과의 생산유발 관계 및 연결구조를 확인한다. 왼쪽은 전방, 오른쪽은 후방연쇄효과로 각각 감응도계수, 영향력계수를 나타낸다.
2-1) 유발계수
최종수요 1단위 증가에 따른 생산·수입·부가가치 유발효과를 산업별로 비교한다. 빨간 체크표시인 평균과도 한눈에 비교할 수 있다.
히트맵으로 수요 1단위 증가시 영향을 많이 받는 상위 20개 산업을 구성할 수 있다.
3) 최종수요 비중
소비, 투자, 수출 등 최종수요 항목별 생산유발 비중을 확인한다.
3. 시나리오 분석
1) 수요충격 변화 시나리오
특정 산업의 최종수요 증가액을 입력하여 산업별 생산·수입·부가가치 파급효과를 분석한다.
2) 산업 간 계수 비교
여러 산업을 선택하여 주요 유발계수와 영향력·감응도계수를 비교한다.
4. 분석안내
산업연관분석에 사용되는 주요 지표의 정의와 계산 방법, 분석 모형 및 결과 해석 방법을 안내한다.


원자료 탐색은 열 산업 검색 결과 중 최대 30개 항목을 표시합니다. 열 산업명을 검색하면 해당 검색 결과의 앞에서부터 최대 30개를 확인할 수 있습니다.
